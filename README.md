# Gefina: do zero à API de faturas

Vídeo animado, em formato de página web, que recapitula o projeto Gefina do curso Full Stack da Digital College. São 13 cenas, cerca de 2 minutos e meio, cada uma com animações e um texto de narração na parte de baixo.

## Ver online

https://vitoriaingrid4571.github.io/gefina-video/

A página precisa de internet para carregar as fontes.

## Controles

| Tecla | O que faz |
|---|---|
| Espaço | Começa, pausa e retoma |
| Seta direita | Próxima cena |
| Seta esquerda | Cena anterior |
| F | Tela cheia |
| H | Esconde os controles |

## O que o vídeo cobre

- Como uma API funciona: front-end, back-end e endpoints
- Express: rotas, `req`, `res` e parâmetros de rota
- Ordem das rotas e o 404 padronizado
- TypeScript, `tsconfig.json` e o script `check`
- Arquitetura em camadas: `server`, `route` e `service`
- `interface` e `type` para tipar as faturas
- Git, issues, critérios de aceite e commits tipados
- Biome: `check`, `fix` e `fix:unsafe`
- Separação em `api` e `web` e o primeiro React

## Como gravar a tela

1. Abra a página e aperte `F` para tela cheia.
2. Comece a gravação do computador.
3. Aperte Espaço para iniciar o vídeo.
